Reiss’s slides for each day are typically drawn from these slidedecks organized by topic:

  • intro

  • logistics (course logistics, might not be updated for current semester)

  • building pdf

  • accountspdf

  • kernelpdf (including exceptions)

  • signals (Unix signals, now typically not covered)

  • unix-api (fork, dup2, etc)

  • virtual memory –

    • vm-intropdf (introduction; what are page tables)
    • vm-faultpdf (tricks with page fault handling; OS memory map versus page tables)
    • vm-formatpdf (storing page tables in memory; multi-level page tables)

  • caching —

    • caching-intropdf
    • caching-dmpdf (direct-mapped caches)
    • caching-assocpdf (set-associative caches)
    • caching-codepdf (correlating code to cache behavior)
    • caching-writepdf (caches and writes)
    • caching-tradeoffpdf (cache tradeoffs)
    • caching-blockingpdf (cache blocking; typically not covered)

  • threadspdf

  • synchronization –

    • sync-reorderpdf (race conditions; interleaving; compiler/processor reordering)
      • sync-ccpdf (cache coherency; typically not covered)
    • sync-lockspdf (mutex-type locks)
      • sync-lock-implpdf (implementation; typically not covered)
    • sync-barrierspdf
    • sync-monitorspdf
    • sync-false-sharepdf
    • sync-rwlockspdf (reader-writer locks)
    • sync-semaphorespdf (typically not covered)
    • sync-xactpdf (transactions, very briefly)

  • deadlockpdf

  • networkpdf

  • securepdf (secure channels, cryptography)

  • pipelinepdf (pipelined processors)

  • ooopdf (out-of-order processors)

  • spectrepdf (side-channels, Meltdown, Spectre)

  • bpredpdf (branch prediction)

Note that these slidedecks frequently contain extra slides that will not be used in most semesters.
